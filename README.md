# LeetCode Checklist (DP + Graphs)

React + Vite app. Ticks are saved in your browser's localStorage (key `dp-leetcode-checklist-v1`).

```bash
npm install
npm run dev      # open the printed local URL
npm run build    # production build in dist/
```

Two tabs: **DP** (`src/data.js`) and **Graphs (Infosys SP)** (`src/graph-data.js`, 129 problems). New sections go at the end of the list so saved ticks keep working.
